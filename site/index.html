What HitLib actually does

Three parts work together: a library that runs on the robot, an editor that builds the animations, and a physical kit that lights up. Here's what each one is for.

Library

HitLib

A PROS-based C++ library that drives WS2812B strips over a VEX V5 Brain's ADI ports. Compose animations like flow, rainbow, pulse, flash, twinkle, bitscroll, and center-spread into named, prioritized modes, or let a strand fill like a gauge that tracks a motor's heat, an arm's rotation, or the battery on its own.

Editor

Pattern Studio

A desktop app that designs those looks against a live preview, then exports them as a ready-to-include C++ header. Drop a song into the Song bar and it bakes the track's loudness into a table your strip fills to as it plays. Hand-writing code is still there as an opt-out.

Hardware

LED Kits

Physical strip and wiring kits from the team, built to plug straight into a VEX Brain. Test kits are already running, and general kits open for order Monday, September 7.

// pattern-studio

One tool for every animation

HitLib is the PROS-based library that drives WS2812B strips off a VEX V5 Brain's ADI ports, with animations like flow, rainbow, pulse, flash, twinkle, bitscroll, and center-spread composed into named, prioritized modes you switch at runtime. Pattern Studio sits alongside it as external software you install once, so you can preview and build any of that live, then export it as ready-to-include C++. No round-trip through code is required unless you want one.

  • Design against a live preview, then export straight to a ready-to-include C++ header.
  • Drag your PROS project onto the window and Deploy writes that header into include/.
  • Drop a song into the Song bar (MP3, M4A, FLAC, OGG, WAV, or MIDI) and the strip fills to its loudness as it plays.
  • Pick an animation such as Rainbow or Twinkle, then tune its speed and palette.
  • Splice Mask splits a strand into sections you can invert or alternate for layered effects.
  • Select multiple strands and group-edit them as a single animation.
  • Writing animation code by hand is still fully supported as an opt-out.

Found a bug or have an idea? File it as a GitHub issue, or drop feature suggestions in #suggestions on Discord.
